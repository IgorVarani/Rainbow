# 🌈 Rainbow Bites

Rainbow Bites é uma aplicação web funcional totalmente focada no front-end utilizando-se de HTML5, CSS3 e JavaScript para criar um imaginário fast-food temático focado no espetáculo visual através das cores do arco-íris e interatividade extremamente dinâmica com o usuário.

---

## 📌 Descrição do Projeto

O **Rainbow Bites** é uma aplicação web que simula o funcionamento de um sistema de pedidos de uma lanchonete moderna, com foco em:

* Interface visual colorida (tema RGB)
* Experiência interativa
* Navegação simples e intuitiva
* Simulação de carrinho e fluxo de pedido

---

## 🚀 Funcionalidades Implementadas

### 🍔 Identidade Visual

* Produtos personalizados criados:

  * Hambúrguer RGB
  * Pixel Nuggets com efeito visual diferenciado
  * Estilo inspirado em fast-food futurista/colorido

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** → Estrutura da aplicação
* **CSS3** → Estilização e layout (incluindo efeitos modernos)
* **JavaScript (Vanilla)** → Lógica e interatividade

---

## 🎨 Estilo e Design

O projeto segue uma identidade visual baseada em:

* Cores neon / RGB
* Tipografias modernas (ex: Share Tech Mono, Audiowide)
* Elementos com blur e transparência
* Interface futurista e chamativa
