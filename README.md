# 🌈 Rainbow Bites

Projeto de aplicação web de um fast-food temático focado em cores vibrantes, experiência visual diferenciada e interatividade com o usuário.

---

## 📌 Descrição do Projeto

O **Rainbow Bites** é uma aplicação web que simula o funcionamento de um sistema de pedidos de uma lanchonete moderna, com foco em:

* Interface visual colorida (tema RGB)
* Experiência interativa
* Navegação simples e intuitiva
* Simulação de carrinho e fluxo de pedido

---

## 🚀 Funcionalidades Implementadas

### 🔐 Sistema de Login

* Controle de tentativas de login
* Exibição do botão "Esqueci minha senha" após erro
* Feedback visual para o usuário

---

### 📋 Cardápio

* Exibição de produtos (hambúrgueres, nuggets, etc.)
* Layout estilizado com identidade visual RGB
* Organização clara dos itens

---

### 🛒 Carrinho de Compras

* Adição de itens ao carrinho
* Listagem dinâmica dos produtos
* Estilização com fontes personalizadas
* Centralização e ajustes de layout via CSS

---

### 📦 Sistema de Pedido

* Tela/modal de pedido
* Confirmação para cancelamento de pedido
* Estrutura preparada para finalização

---

### ✅ Botão "Concluir Pedido"

* Exibe alert ao usuário
* Registra ação no console (`console.log`)
* Representa o fechamento do fluxo de compra

---

### 🍔 Identidade Visual

* Produtos personalizados criados:

  * Hambúrguer RGB
  * Pixel Nuggets com efeito visual diferenciado
* Estilo inspirado em fast-food futurista/colorido

---

### 🎠 Componentes Interativos

* Carrossel de imagens funcional
* Navegação entre slides (anterior/próximo)

---

### 📱 Menu Lateral

* Menu estilo hambúrguer
* Navegação entre páginas
* Ícones visuais para melhor UX

---

## 🛠️ Tecnologias Utilizadas

* **CSS3** → Estilização e layout (incluindo efeitos modernos)
* **JavaScript (Vanilla)** → Lógica e interatividade
